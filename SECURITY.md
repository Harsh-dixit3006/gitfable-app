# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is unavailable, contact the maintainer through GitHub before disclosing anything publicly.

Please include:

- A description of the issue
- Steps to reproduce it
- The affected area or file, if known
- Any suggested mitigation

## Response Expectations

The goal is to acknowledge reports promptly and work toward a fix before public disclosure.

## Scope

This applies to the GitFable application, deployment scripts, and repository configuration.
